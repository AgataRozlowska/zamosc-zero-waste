# Zamość Zero Waste

Katalog napraw dla mieszkańców Zamościa: krawcy, szewcy, zegarmistrze, serwisy AGD, tapicerzy i inni fachowcy, którzy naprawiają zamiast wymieniać na nowe.

- `index.html` – strona o projekcie
- `aplikacja.html` – wyszukiwarka fachowców
- `config.js` – ustawienia (e-mail na zgłoszenia, mapa, wydarzenia)
- `dane.js` – baza zakładów

Szczegóły uruchomienia i edycji: `INSTRUKCJA.txt`.
